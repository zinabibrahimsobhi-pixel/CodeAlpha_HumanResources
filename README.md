# Human Resources Analytics Dashboard

## Project Overview
This project analyzes employee data using Power BI to explore employee attrition, job satisfaction, performance ratings, and work experience.

## Objectives
- Analyze employee attrition across departments and job roles.
- Explore employee job satisfaction and performance ratings.
- Understand the relationship between overtime and attrition.
- Review employees' years at the company and distance from home.

## Tools Used
- Microsoft Power BI
- IBM HR Analytics Employee Attrition & Performance Dataset

## Dashboard Pages
1. **HR Overview & Attrition**
2. **Employee Performance & Satisfaction**
3. **Employee Work & Experience**

## Key Metrics
- Total Employees: 1,470
- Employees Left: 237
- Active Employees: 1,233
- Average Monthly Income: Approximately 6.5K
